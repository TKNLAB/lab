1 · Before you start

  1. Keep a copy of the whole site folder (nayak-lab-site) on your computer. This dashboard lives in it and is not uploaded to the server.
  2. Open Dashboard.dc.html from that folder in Chrome or Edge.
  3. Click Open site folder and choose the nayak-lab-site folder (the one containing index.html). Allow the browser to edit files when it asks.

2 · Edit

  • Lab updates: newest first; the first 4 show on Home.
  • Publications: paste a DOI link in “Link”, press Fill from DOI, then check the authors and journal.
  • People: drag the ⋮⋮ handle to reorder, or drag a card between Lab members and Alumni. Click a photo to replace it.
  • Member updates: lab members fill in add.dc.html and email you a profile-….json file. In People, click Import member update…, check the changes, Accept, then Save.
  • Teaching: add or edit courses and their images.
  • Gallery: upload several photos at once, add captions, drag to reorder. The first is featured; the first 4 show on Home.
  • ↑ ↓ move an item, ✕ deletes it. Photos are resized and converted to .webp automatically.

3 · Save

  1. Click Save to folder. This rewrites data/content.js and writes new images into assets/people, assets/gallery or assets/courses.
  2. The previous content.js is kept in data/backups/, so any save can be undone by copying a backup back.
  3. Click Preview site ↗ to check the pages locally.

4 · Publish

  1. Upload data/content.js to the same place on the server, replacing the old one.
  2. Upload every new image listed in the save message into the same assets/… folder on the server.
  3. Never upload Dashboard.dc.html, README.md or data/backups/. add.dc.html is safe to upload so members can reach it.
  4. If the site still shows old content, hard-refresh the page (Ctrl+Shift+R / Cmd+Shift+R).

Using Safari or Firefox?

These browsers can't write into folders. Edits still work, but Download files saves content.js and any new images to your Downloads folder instead. Move content.js into data/ and each image into the folder named in the message, then upload as in step 4.
